# 会议详情参考与实现边界

参考入口：https://100wiser.com/knowledgeBase?kbTab=voiceNote

2026-09-23 使用已登录的浏览器逐项查看会议详情与配置弹窗。实现保留 Eureka 的全局导航和首页，用项目现有 20 条模拟会议承接详情，不复制参考账号的会议原文、客户或位置数据。

## 已观察并实现

- 左侧录音文件列表、选中状态、列表收起、顶部搜索、标题修改、元信息、关闭详情。
- 参会人编辑与发言片段试听；客户/商机 CRM 与非 CRM 选项、位置、标签；图片添加、预览和移除（本会话内）。
- 音频播放、暂停、拖动、前后15秒、倍速。使用本地合成的33秒中文演示音频，播放器时长据真实音频显示。
- 智能总结、转译文本、实时翻译、思维导图、图文摘要、逐字稿，顺序与参考一致。
- 总结模板分类、模板选择、语言和详细程度配置；评分反馈。
- 独立新标签页编辑器：标题、正文、基础格式、字号/字体、撤销重做、Ask AI演示、保存及未保存离开提示。保存跨页面同步，并检测同时修改同一正文/标题的冲突。
- 更多菜单：导出内容选择 → TXT/JSON格式选择 → 实际下载，音频可导出WAV。
- 分享类型、内容选择、有效期、记录与本地预览；没有连接分享后端时明确告知不能创建公开链接。
- 删除沿用已有确认和回收站逻辑，可恢复且保留本地编辑。

## 已观察但仅模拟的服务能力

- 未在参考账号触发重新总结、生成结果、真实分享、反馈提交或删除，以免改变账号内容/消耗积分。
- AI生成后的内容、思维导图、图文摘要、逐字稿、AI编辑建议均为明确标注的本地演示。
- 参考“生成深度报告”打开带当前转译/总结附件的创作页面，没有自动提交。本地提供引用当前会议的创作要求、可编辑演示提纲和下载。
- 参考“AI智绘PPT”打开新空白页后自动关闭，未能获取其后续界面。本地保留入口与可编辑提纲流程，不声称已还原未观察到的下游PPT界面，也不生成真实PPT文件。
- 没有真实CRM查询、AI推理、积分发放、云端文件存储或公开链接服务；用户输入的修改保存在当前浏览器。
