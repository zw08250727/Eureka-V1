# 百智与 EurekaMind 登录流程

更新：2026-10-12。产品界面不承载下述实现和评审说明。

## 线上核对与实现范围

来源：https://100wiser.com/index 。实际浏览并点击登录窗口，确认百智个人登录支持手机号/邮箱验证码、新用户自动注册、用户服务协议与隐私政策勾选；企业登录首先填写企业代码，并提示向管理员获取。

本仓库默认进入平台首页，需要账号的操作才打开登录覆盖层。国内只有 **个人/团队版** 和 **企业版** 两个入口。企业代码之后的线上页面未凭有效企业身份验证，本次按用户要求补齐独立原型：代码校验 → 企业成员手机号/邮箱登录 → 企业工作台。企业工作台实现待办创建、完成、删除、刷新保存、成员信息与退出，未宣称覆盖完整企业业务。

海外保留 Google、Apple、邮箱登录及注册。国内品牌百智，海外 EurekaMind；分流页白底简洁入口。协议入口当前打开百智官网；线上协议由登录窗口打开，并无已核实的独立文档 URL。正式协议全文及链接由登录 PM 后续对接。

## 验收数据

| 流程 | 输入 |
| --- | --- |
| 百智个人/团队手机号 | 任一格式有效的国内手机号，例如 13900139000；验证码 111111 或 123456 |
| 百智个人/团队邮箱 | 任一有效邮箱，例如 member@example.com；验证码 111111 或 123456 |
| 百智企业代码 | 100001（青禾科技） |
| 企业成员 | 林晓：13800138000 或 lin@qinghe.example；验证码 111111 或 123456 |
| 海外邮箱 | 任一有效邮箱，六位数字验证码（建议 123456） |

首次载入输入为空，协议默认不勾选。国内点击“获取验证码”在格式校验通过后自动填入 111111；手动输入 111111 或兼容旧值 123456 均可继续。仍校验手机号/邮箱格式、协议勾选和企业成员资格。个人/团队账号登录后可在两个工作区间切换；团队资格仍遵循 ACCOUNT-01。企业成员必须存在于独立成员表，不能通过登录自动加入企业。企业代码错误、成员不在企业、格式错误、验证码错误及存储失败均有反馈。

## 数据域与服务边界

- 国内个人/团队：`eureka:market:cn:eureka:auth:v1`；海外：`eureka:market:global:eureka:auth:v1`。
- 企业：`eureka:market:cn:enterprise:auth:v1`，realm 为 `baizhi-enterprise:100001`。业务资料键包含企业代码和成员身份，不读取个人/团队工作区资料。退出企业仅删除企业会话。
- 验证码、OAuth、企业目录都是本地 fixture，未调用短信、邮箱、认证服务；协议勾选不提交线上。支付、发票、Agent、连接器授权、定时任务、录音与外部导入维持原型服务实现，不连接真实服务。
- “模拟支付失败”等注入、账期推进及身份切换只在显式 `?review=1`（或历史回归路径）显示。正常产品流程保持产品文案；实现限制与待确认数值留在仓库。
- 前端隔离用于原型，生产权限必须由服务端落实。此次未变更既有同市场共享 fixture 人物的基础模型，未实现真实账号的用户级后台隔离。
- 既有浏览器资料不会自动改名或迁移；新国内初始团队名为“百智 产品团队”。验收新品牌使用干净浏览器上下文。

## 当前登录布局与企业提示（2026-10-12）

- 点击企业版或直接访问 `?edition=enterprise` 时出现“以线上为准”toast，4.5秒自动消失，可关闭；不阻断企业代码及成员登录。这是用户明确要求的演示文案例外。
- AUTH-UI-01：两地默认进入首页，登录覆盖层复用白底单列表单，宽度不超过400px；右上角关闭或 Esc 返回首页，Tab 焦点不离开窗口，短屏内部滚动。
- 不再挂载右侧截图、示意图或自动轮播。国内个人/团队与企业两入口、企业代码流程、手机/邮箱切换、海外渠道及注册切换保持。
- 历史展示组件与 assets 目录保留作为参考，不作为当前登录页验收标准；不生成替代示意图。

## 首页校验清单（AUTH-GUEST-01）

| 入口 | 未登录行为 | 登录后 |
| --- | --- | --- |
| 首页 | 可浏览，空状态与登录引导 | 本人工作区 |
| 商城、App 下载 | 保留免登录访问 | 无需账号校验 |
| 录音 | 登录窗口，不请求麦克风 | 录音权限确认 |
| 上传 | 登录窗口，不读取文件 | 上传窗口，用户重新选择文件 |
| Ask Agent、帮我安排 | 登录窗口，不执行或扣费 | 展开 Agent，用户发起任务 |
| 会议搜索、回收站 | 登录窗口，不显示会议 | 首页或回收站 |
| 日程待办、闪念、灵感、记账、通讯录 | 登录窗口，无私有资料 | 对应模块 |
| 连接器 | 登录窗口，不展示授权 | 连接器，仍需单独授权 |
| 积分、会员升级、通知 | 登录窗口，不显示余额 | 对应账户功能 |
| 工作区、创建/加入团队、账号 | 登录窗口，“登录 / 注册”文案 | 对应首页、团队创建或邀请页 |
| 私有深链 | 游客首页上自动打开登录窗口 | 续接原目标；取消回公开首页 |

企业 `?edition=enterprise` 兼容旧入口，在首页上打开企业代码步骤，认证后仍独立进入企业工作台。跨标签退出会卸载私有界面，游客不能看到原人物、会议、余额或团队。登录续接只打开工具，不自动录音、上传、运行 Agent、授权或购买；消费后删除一次性 URL 意图，刷新不重复打开。
