## 工程边界与人工自查

- 产品改动均位于现有 `src/features/`、`src/components/` 的 Next.js／React／TypeScript 组件和模型；无新增独立 HTML 产品页、业务 iframe、原生业务存储访问或手改冻结原型／生成 `prototype.css`。
- 日程编辑网格、共享确认和危险操作样式使用模块 CSS；颜色、字号取 `ui-foundations.css` 语义变量。删除确认复用 `ReferenceDialog`，未保存确认复用现有 `PaModal`／`RefDialog`；未引入第三套关闭、遮罩或焦点管理。
- 参与人文本与团队成员 ID 分开保存。新增成员的共享和移除成员的撤权均由账号持有人在保存确认弹窗中选择；模型在写入前重查成员、归属、版本和团队权益。只读、到期、离队及管理员代共享不会因 UI 操作获得额外权限。
- 周总结仅读取当前身份可见、上一完整自然周的会议；无资料时显示空态。Agent 输入框只显示简洁问题，周期指令、授权会议 ID 和输出结构独立传递；来源 ID 会校验。当前本地展示使用已保存记录的即时预览，真正语义生成依赖后续 Agent 服务接入，不将预览冒充远端生成结果。
- 用户反馈驱动的人工修正：撤权专用文案不再误写“共享后”；团队新增日程弹窗上叠的共享确认在桌面和 390px 宽度下无横向溢出；“放弃修改”归入已有弹窗页脚；移动端周总结操作的触控高度不低于 44px。团队首页已无“新建笔记”入口，清除了不可达的本地状态与弹窗代码。

## 验收与回滚

Given 当前市场的个人或团队工作区，When 打开日程编辑／共享确认／Agent 上下文／周总结，Then 仅展示本市场、当前账号有权读取的记录；失效授权在保存或发送前重新校验。Given 390、768、1080、1440px 视口，When 打开编辑字段与确认弹窗，Then 字段对齐、控件可触达、内容不横向溢出。Given 删除或未保存修改，When 取消或关闭，Then 保留原资产与输入；确认成功后才更新界面。
