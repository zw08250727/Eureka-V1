# 个人与团队工作区交互调整（2026-10-09）

## 已确认规则

- 统一账号，多 Team 各自维护成员、设置、账单与一套权益。管理员付费不带来内容访问权。
- 首页、开始录音、日程与待办、我的客户一级入口一致；团队工作区分组为团队成员、设备查看（管理员）、空间设置、开放API调用。
- 团队首页复用本人日程、待办、灵感与记账模块，按授权展示共享闪念；增加 Agent 团队简报。录音复用个人权限申请流程。
- 内容默认私有。在空间设置的内容权限 Tab，所有成员仅设置当前工作区自己的会议／闪念开关及接收人，覆盖硬件、软件、上传与笔记；仅影响后续记录，不补历史，不跨 Team 复制，不自动授权新成员。
- 硬件新录音按录制时绑定区归属，迟到补传锁定原绑定记录；切换不迁移、合并历史。移除已失去访问权的迟到事件拒绝入库。
- 设备由本人管理并固定绑定一个工作区；团队页仅管理员可看元数据，无绑定、解绑、模拟同步或内容设置；本人在个人设备页／App 解绑。
- 管理员移除成员后保留已共享历史和设备绑定，清除该区后续共享配置；没有主动退出／解散入口。
- 到期或取消生效进入只读：保留历史检索，暂停手动创建、编辑、上传和 AI；设备新录音仍保存原始音频，不转写／不扣费，恢复后进入待处理队列。
- 当前规则：在哪个工作区就使用该区权益。加入或移除 Team 不阻止个人使用；内部结算状态不展示为冻结卡片或标签。
- 客户企业／自然人双主体，仅手动或 CRM 添加；同成员同工作区跨 channel 归一，CRM 优先，不跨成员归一。详情会议跟进、双方待办及来源画像；创建跟进复用当前工作区私有日程。

## 验证范围

检查授权开关、未获邀管理员不可读、成员移除与历史保留、多 Team 配置及用量隔离、到期原始录音例外、个人与团队用量隔离、旧页面拒绝写入、失败回滚、同录音权限流程及桌面／窄屏布局。所有支付、邀请、硬件与 AI 为本地演示。

## 最新修订：工作区设备绑定与编辑授权

用户明确改为设备固定绑定工作区。设备仍由本人管理，团队管理员仅查看当前区已绑定设备。个人设备页提供本人设备的绑定、解绑及明确确认的换绑流程；切换页面不换绑，旧录音及离线补传保持原绑定工作区。旧数据中缺少绑定区的设备需要本人确认，不能用当前视图推断归属。成员移除不由管理员解绑，原绑定仍显示，但原团队同步拒绝且不改投个人空间。

共享按当前工作区的接收成员分别设置查看或编辑。编辑包含内容修改，不含删除、转授权或修改设备绑定；空间到期仍覆盖编辑权限。默认开关授权只影响未来内容，详情可修改单条权限。实现顺序：绑定与授权模型／迁移、设备及权限交互、详情编辑校验、跨区和撤权回归、PRD与视觉验证。保留旧文件和已有工作树改动。

最新确认：硬件设备固定绑定工作区，切换页面不换绑，必须本人明确解绑再绑定；A 期间录音及离线补传仍归 A。账号菜单「我的设备」管理本人绑定，团队设备查看保持管理员只看元数据。当前团队共享逐成员提供查看／编辑，编辑不含删除或转授权，且不能绕过到期只读。

## 团队首页整合布局

用户要求重新布局，撤下“个人概览整块 + 团队简报整块”的纵向拼接。采用一个工作概览面板：左侧为主要阅读区（Agent 团队简报、结论、可展开会议依据），右侧为当天执行区（日程与待办、安排入口）；右侧底部用紧凑双列展示灵感与记账。有内容展示记录，无内容缩成一句提示，避免等高空卡占位。会议列表紧接概览。页面顶栏统一录音、上传、Agent 与笔记操作。窄屏转为单列，保留层级与所有入口。

实现采用团队专用展示组件和局部 CSS，复用原有授权数据、日期规则、待办保存与录音授权回调；不修改个人首页、设备绑定、成员权限及权益逻辑。依次完成组件整合、三档屏宽与真实内容／空态验证、相关交互回归和 PRD 说明同步。

## 首页紧凑化修订

按用户要求，每条团队简报默认三行：标题、单行摘要、来源与操作。将会议依据入口并到第三行；展开后可读完整摘要和来源，不丢失截断内容。缩小概览内边距、条目间距和右侧空态占位，维持当前左右分区及原有业务数据和权限。实施顺序：调整展示组件与局部样式，构建并验证三种宽度、依据展开与 Agent 侧栏。

## 最终确认：闪念仅归个人

本节覆盖前述团队今日安排及闪念共享设计。团队首页仅保留紧凑三行简报与会议列表，移除日程、待办、灵感、记账及其团队入口。设备会议按绑定工作区保存；闪念始终归设备所有者个人区，不共享，团队设置只保留会议查看／编辑。旧团队闪念按所有者迁回并撤销授权，保留已有个人修改；旧团队日程不删除、不迁移，停用旧入口与写入。个人区按本区套餐处理闪念，不扣团队权益。

最新视觉修订：删除团队简报底部范围／模拟说明；来源、问问 Agent、查看会议依据改为跟随正文的行内内容，窄屏自然换行，不单独占用一行。此项覆盖此前三行展示规则，业务权限不变。

## 团队客户共享

个人入口为我的客户，团队入口为团队客户。团队内容权限新增本人客户共享开关，默认关闭；开启即向当前所有有效成员开放当前区已有及未来客户，关闭立即收回但不影响查看别人共享的客户。列表聚合自己的记录与已开启共享的成员记录，按成员和客户 ID 组合识别，不跨成员去重归一，标注所属成员并支持筛选。共享仅查看，原记录由所属成员维护；关联会议仍单独鉴权。来源筛选为手动录入、CRM、Agent 创建，旧会议／闪念来源统一映射到 Agent 创建。关闭、移除和跨区切换后清除页面与详情中的过期可见结果；旧快照分享入口停用，避免绕过客户开关。
