## 本轮补齐

- 联系人模型写入返回失败时，UI 保留表单并回滚内存；成功提示在重新渲染后显示。
- 备注 / 跟进空白输入显示就地错误；备注保存后直接展示，跟进保存稳定 contactId 与完整描述，刷新保留。
- 搜索不再调用不支持的 search 输入选区 API；Alice 等联系人不再套用 John 的承诺 / 首次认识时间。
- 联系人弹窗支持初始焦点、Tab 循环和 Escape；备注数量与标签使用实际记录。
- 联系人与个人上传增加存储快照冲突保护，阻止旧标签页覆盖新数据。
- 语言 / 自动摘要保存失败时保留最后成功状态，开关说明与实际状态一致。
- 团队开通确认信息持久化，支持关闭 / 刷新恢复、取消清理、失败重试、跨页冲突保护与成功防重。
- PRD 以规则分块，并排对照截图；去掉模块独立配图小节，更新设置、设备、Agent、联系人等冲突文字。

## 已知模拟边界

| 能力 | 当前行为 |
| --- | --- |
| 团队任务管理 | 按用户要求点击仅提示“即将上线”；不新增真实管理页 |
| 麦克风 / ASR / AI / 联网 | 计时、演示音频与示例回答；不代表真实服务连接 |
| 上传 | 保存元数据，不存储上传文件本体；不虚构转写 |
| 自动任务 | 配置和手动模拟运行；不在浏览器关闭后调度 |
| 通知 / 邀请邮件 / 支付 / 硬件 | 本地状态模拟；真实发送、支付回调与设备认证待服务接入 |
| 团队开通草稿 | 确认信息后可从创建入口恢复；未确认的输入不自动持久化。真实支付回调与开通恢复仍需服务端 |
| 数据并发 | 浏览器快照检测；不替代服务端事务、认证和跨设备同步 |

## 团队退出、解散与权益收尾

- 成员页增加所有有效成员可用的「退出团队」。唯一管理员被阻断并可直接前往成员管理交接，或改走解散流程。
- 管理员空间设置增加「解散团队」，输入完整团队名称确认；取消、错误名称、过期快照、保存失败均不改变团队或权益。
- 退出释放本人占用席位、撤销本人转写授权、解绑本人设备、暂停本人团队自动任务；保留团队已购席位、续费、Credits、原资料 ACL、个人套餐与其他团队。
- 解散终止全部成员及邀请、订阅续费、下期变更、未支付席位 / Credits 订单与自动任务，解绑全部团队设备。原账单与余额冻结快照留档，不自动退款、转移或清零。
- 解散结算记录可在完成弹窗和个人订阅页面重新下载；空间列表隐藏已退出 / 解散团队，旧标签页同步撤销访问。存储失败整批回滚。
- 空间切换列表移除 Team Unlimited 说明，保留角色与有效人数。
- PRD revision `prd-20261007-38` 增补 MEMBER-07/08、SETTINGS-07–09、BILL-EXIT、CREDIT-EXIT、模型与验收；规则旁附退出、交接、解散确认和结果配图。
- 原型不进行真实扣款 / 退款。真实剩余订阅及 Credits 退款、发票、晚到支付、数据保留期限为明确的商业 / 财务 / 法务上线依赖。
- 自动验证：新增模型测试及 6 条浏览器端到端用例；覆盖成员权限、最后管理员保护、权益隔离、终态不能续费、失败回滚、并发失效、跨标签页撤销与小屏。
- 验证结果：`npm run check`、静态构建通过；全量浏览器回归 113 通过 / 2 条条件截图用例跳过；最终生命周期专项 6 条通过。已到期团队可在不续费的情况下交接管理员后退出。
