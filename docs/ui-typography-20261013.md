# 两地 UI 字号与团队导航调整

本轮依据用户要求恢复两版团队一级入口，并重新梳理全局文字层级。主责为公共 UI／账号工作区模块，关联联系人、会议、日程、闪念、连接器、Agent、订阅与积分；负责人待认领。适用国内／海外个人、团队管理员及成员。

## 设计与实施

UI-NAV-02：团队成员、设备查看、空间设置、开放API调用在展开侧栏显示文字；手动折叠及中等宽度自动折叠仅隐藏文字 span，按钮保留无障碍名称和悬浮提示。设备入口继续遵循原有管理员权限。

UI-TYPE-02：首页欢迎／认证24/32，一级页面22/30，二级分区16/24，三级卡片14/22，弹窗18/26（内部16和14），正文14/22，导航13/20，摘要和筛选12/18，短标签11/16。最小字号仅用于状态、分类、计数等短标签；操作、说明和客户摘要不低于12px。长篇会议正文保留15px。字号缩小不缩小点击区域。

复用现有 ui-foundations token、market-workbench 兼容层、ReferenceShell、Select、ReferenceDialog。新增 market-typography.css 仅补充现有 React 页面缺失的角色映射。样式文件属于展示层；shell.tsx 为混合层，只改导航文字结构和可访问属性；分享页仅改标题样式。无模型、存储、权限、支付或跨市场契约变更。两地共享尺寸、保留各自字体和颜色，不改生成文件与冻结原型。

实施顺序：修复导航 → 统一语义字号 → 按路由检查标题/卡片/筛选/浮层 → 同步规范 → 构建、双市场浏览器验证与截图。对 UI-TYPE-02 修订旧视觉断言，不以历史字号作为新业务规则。
