# 功能流程复查修复记录

分支：`codex/fix-workbench-flow-gaps`。修复对象为原生 `/workbench/` 页面，沿用已确认的联系人、个人首页和团队简报 PRD 规则。

## 已修复

| 范围 | 修复行为 |
| --- | --- |
| 无效对象 | 联系人不存在时显示明确空态，不回退到其他联系人；团队历史失效时不展示另一段会话 |
| 个人首页 | 以时间区间判断跨天日程；进行中优先、已结束不作为下一场；历史逾期待办纳入展示；区分无待办和全部完成 |
| 无期限待办 | 支持空截止时间，进入“未安排”，不产生提醒或逾期；编辑继续使用原记录 ID |
| 记账 | 独立保存收支发生日期、币种和实际／计划性质；支出与收入分开、各币种分别汇总；保留原始捕获及来源；旧版人民币数据保留兼容读取 |
| 联系人 | 同名允许独立建档；支持资料编辑；两侧承诺独立展示，按稳定 ID 去重计数；可更新承诺状态；明确期限才显示逾期；备注可编辑删除；记忆区分待核实与用户确认 |
| 联系人统计 | 仅计算可访问且参与身份已核实的独立事件，活跃主题取最近 30 天；不继续沿用种子数据中的虚构统计数 |
| 多页编辑 | 联系人数据跨标签页更新；已打开的旧表单拒绝覆盖新数据并保留输入；同页变更同步刷新工作台数据 |
| 录音 | 个人录音保存为网页录音，保留当前演示转写、摘要及重点标记；个人／团队录音 Agent 会话进入历史；新建会话与历史入口并列；保存后可直接查看会议 |
| 团队简报 | 基于当前可读且已总结的会议，使用最近 7 个自然日及旧未闭环事项；按议题标识聚合、按会议去重、校验引用原文；失效证据不再进入结论；沉默不关闭事项；上传者标为资料提供者 |
| 共识标注 | 同一明确结论具备多场会议及多位发言人依据时才标为共识；单场会议明确标注为单次要点；事实与后续建议分开 |

## 实现边界

- 个人资产生成复用现有 App 闪念逻辑，本次只修复读取、展示和已支持的手动编辑流程。
- 当前项目仍为本地交互原型。真实 ASR、模型推理、MCP／skill 调用、联系人提取及后端权限服务未因本轮修复而接通；结构化取值规则的测试不等于这些外部服务联调通过。
- 无法证明参与身份或来源的旧联系人记录，不追补虚构互动数；原始资料和人工修改保留。
- 本轮不调整已确认 PRD 的业务口径，未发布到线上。
