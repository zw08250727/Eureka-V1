# Eureka

EurekaMind 团队工作台交互原型，采用 Next.js App Router 作为工程入口，原型页面和资源按模块收纳在 `src/prototype/`。

## 本地运行

```bash
npm install
npm run dev
```

访问 <http://localhost:3000>，进入登录 / 注册演示；完成后直接进入个人工作台首页，无用途问卷或信息收集步骤。

## 质量检查

```bash
npm run check       # ESLint、TypeScript、原型资源引用和模型测试
npm run build       # 生产构建
npm run test:e2e    # Playwright 浏览器测试（需先安装依赖）
```

原型自身的模型测试位于 `src/prototype/one-to-one-reference/tests/`，覆盖联系人、应用数据筛选排序、编辑权限、团队数据隔离和导出行为。

## 目录约定

- `src/app/`：Next.js 工程入口和页面壳层
- `src/prototype/`：最终交付的 HTML 原型、样式、脚本、素材和模型测试
- `scripts/`：原型资源准备、静态引用检查和测试入口
- `docs/prototype-import.json`：纳入仓库的原型文件校验清单
- `.github/workflows/ci.yml`：提交和 Pull Request 的自动检查

## 分支策略

- `main`：可交付稳定版本
- `develop`：日常集成和下一轮迭代
- `feature/<name>`：功能开发
- `fix/<name>`：问题修复

本仓库只提交脱敏的原型代码与资源，不提交 `.env`、构建缓存、依赖目录或本地运行产物。

## Team 工作空间演示（2026-10）

从左上角工作空间菜单进入，账号保持统一：

- 个人空间：保留现有会议、闪念、联系人与 Agent。个人订阅独立于 Team。
- EurekaMind 产品团队：管理员场景，演示成员邀请/接受/撤销、角色管理、席位、账单、设备、Credits与空间设置。
- 设计共创空间：普通成员场景，只能访问自己创建或被分享的文件。
- 工作空间邀请：接受「增长研究小组」邀请后，新增一个独立团队。
- 创建团队：方案 → 空间信息/席位/周期 → 模拟支付（支持失败重试）→ 开通/邀请成员。

团队首页围绕会议展开：连续的 Agent 团队简报（内容与数量由实际发现决定，同一议题合并叙述）、可核对的会议原文与完整会议列表。不展示个人日程、待办、灵感、记账和全部闪念，也不提供独立「团队文件」或通用文件管理入口。团队会议保留创建人，移除重复的创建成员列及列表导出/分享入口，复用六页签详情、播放器、原位编辑、导出、成员分享、回收站和页面内 Agent。团队不提供联系人入口，个人联系人完整保留。侧栏历史会话仅展示本人，移除成员归属标签，支持悬停删除及“全部任务 / 自动任务”切换。自动任务支持编辑、启停和手动模拟运行，不进行真实后台调度。Agent 支持引用资料、联网开关、回答模式及拖拽调整宽度。默认产品团队有 12 条录音（张伟视角可见 11 条）；旧数据增量补齐，新建团队保持空态。

Team 只使用一种 Unlimited 席位；邀请占席，移除成员释放席位但不自动减账单；加席通过数量预览 → 费用确认 → 模拟支付 → 成功后才生效，支持失败重试、取消、待付恢复与幂等账单；减席与周期切换安排到下一账期，可通过「模拟下一账期」验证。管理员可以管理成员与设备元数据，但不会获得成员私有录音的访问权。设备支持手动录入 SN、型号并绑定成员：管理员可选团队有效成员，普通成员仅本人；重复 SN 拒绝，长数字与前导零按文本保留。原设备申请 / 发放入口已替换，历史设备保留。“绑定已有设备”打开下载 App / 购买设备双入口弹层，实际绑定在手机 App 内完成；Web 不再模拟直接改绑，切换空间不会改变同步目标。首页统一通过「上传」接收 m4a/mp3/wav/opus/flac/aac 音频，旧纪要 JSON 导入入口已撤下；会议详情仍支持导出演示 JSON。

EurekaMind 独立采用 Team Credits 共享池：所有成员的 Agent 会话及自动任务按输入/输出 token 模拟用量扣减，不按席位分配或按次固定扣费；与成员转写权益、个人空间 Credits 分别记账。额外购买包含套餐、订单、失败重试、取消、刷新继续支付、成功到账与下载账单，支付成功只发放一次。演示费率为每 1,000 输入 tokens = 1 Credit、每 1,000 输出 tokens = 2 Credits，保留三位小数；生产须使用模型实际返回用量及服务端费率。团队页面底部可切换演示成员视角验证权限。该入口仅用于本地原型测试，不代表实际身份切换或服务端授权。

数据模型：`assets/workspace-model.js`；界面：`assets/workspace-ui.js` / `.css`。新增状态保存在 localStorage 的 `eureka:workspaces:v2` 中，不覆盖旧团队原型或个人会议存储。付款、邀请邮件、设备通信和 Agent 均为本地模拟；下载的账单不是有效发票。所有价格为 EurekaMind 演示假设。生产环境仍需接入身份认证、租户级授权、支付和设备服务。

参考：实际访问 [Plaud Web](https://web.plaud.ai/) 与 [团队方案页面](https://web.plaud.ai/member/workspace/plan?from=profile_dropdown)，并核对 [工作空间](https://support.plaud.ai/hc/en-us/articles/57744144794393-What-is-a-workspace)、[席位规则](https://support.plaud.ai/hc/en-us/articles/57744114159641-What-is-a-seat)、[设备绑定](https://support.plaud.ai/hc/en-us/articles/57674058082841-Device-management) 官方说明。参考其账号与空间边界，UI 沿用 EurekaMind 现有设计。

## 产品 PRD 与需求评审网站

- 网站：`/prototype/prd/index.html`（与交互原型使用不同 URL，同一仓库 / Pages 部署）。
- 原型顶部新增「需求评审」入口，新标签打开 PRD，不打断当前工作内容。
- 内容源：`src/prototype/prd/content.json`。35 章涵盖个人版与 Team、用户故事、功能优先级、页面规则、异常、数据、上线约束和验收；附当前原型截图及渲染流程图。参考 PDF 本身不入库。
- 支持章节导航、全文匹配搜索、链接锚点、逐章 Markdown 编辑和实时预览、评审记录、JSON / Markdown 导出、JSON 导入和打印。
- **保存本地**：立即更新当前浏览器，持久化到 `eureka:prd:draft:v1`；未保存输入按标签页存入 sessionStorage。其他访客不会看到本地稿。存储失败保留输入；并发标签页修改会阻止旧稿覆盖。
- **发布给所有人**：点击「发布修订」，复制 / 下载完整 `content.json`，通过 GitHub 编辑页提交到 `develop`（受保护时提 PR 合入）。Pages 成功后所有访客刷新可读取新基线。网站不存 GitHub Token，不模拟自动提交，不宣称复制等于发布。
- 新发布基线与旧本地稿冲突时，明确对照并确认合并。对照工作稿与仓库发布版时，产品的会议 / Team 数据不会被清除。
- 实时多人协作尚未提供；需要另行接入身份、授权、数据库和版本合并服务。当前采用静态文档 + Git 版本发布，适合当前部署条件。

验证：`tests/e2e/prd-review.spec.ts` 覆盖编辑刷新、取消、独立浏览器基线、导入导出、无效输入、脚本净化、跨标签页冲突、存储异常、旧基线冲突、响应式、深链接和原型入口。刷新演示截图时先构建，再显式运行 `PRD_CAPTURE=1 PLAYWRIGHT_CHANNEL=chrome npm run test:e2e -- tests/e2e/prd-review.spec.ts -g 'capture current'`，随后重新构建。

团队情报使用已授权会议的当前正文进行本地规则模拟，至少两场会议、两位创建成员才形成交叉线索。首页展示日期与唯一主标题，每条线索仅保留「问问 Agent」，右侧展开并携带当前问题与会议来源；发送后展示交叉依据，支持继续追问；来源撤回、删除或正文更正后重新计算，未修改的旧演示数据增量补充，个人数据保持独立。

团队设备录音：设备同步到其绑定的 Team 后，自动向该空间全部有效成员开放，无需分享；列表、详情和 Agent 共用此范围。其他成员只读，编辑/删除仍限所有者。设备改绑不迁移历史录音，Personal 设备、网页录音与导入的私有记录保持原规则。

加席演示按新增数量的完整当前周期价格计费（年 ¥1,908 / 席位、月 ¥199 / 席位），成功后清除计划减席，现有续费日与计划周期切换保持。正式按比例计费策略待确认。未支付订单保存在对应空间的 seatOrders；权限、报价状态与本地存储冲突均在提交时重检。测试：`tests/e2e/seat-payment.spec.ts`。


## 个人日程与待办、订阅（2026-10-07）

个人侧栏「日程与待办」位于联系人上方，与首页、全部闪念共用记录。日、周、月支持同一时刻的两类条目、跨日显示、日期跳转、详情与编辑。新建使用轻量弹窗，保存后回到日历；日 / 周 / 月均有行内编辑入口，直接弹窗修改；未保存退出有保护。日历不提供搜索和状态筛选。右侧 Ask Agent 采用共享图标，支持当前日期范围的本地分析、来源跳转，以及确认草稿后创建日程或待办；桌面并排并可拖宽，窄屏纵向适配。个人设置移除日程与待办提醒模块，单条记录仍保存提醒字段。

个人订阅按移动端参考演示标准版 400 分钟、Pro 月付 $17.99 / 年付 $99.99；Pro 每月 5,000 Credits 与 99,999 分钟。订单支持模拟成功、失败重试、取消、刷新续付、下载 USD 账单、取消自动续费和本浏览器恢复购买。付款成功才更新个人权益且一次入账，不改 Team。首期 Credits 可验证到账；后续月度刷新与真实自动扣款需后端服务。切换月/年套餐按全额重新起算演示，正式差价规则待确认。

新增模型 `personal-subscription-model.js` 与 `personal-calendar-subscription.spec.ts` 覆盖订单幂等、存储失败、日历/弹窗/Agent 布局和各屏幕尺寸；PRD 的个人日程、个人订阅与验收章节已同步配图。

顶部工作空间选择器与左下角账户菜单分别呈现：顶部提供空间切换、创建团队、工作空间邀请，当前 Team 管理员另有「邀请空间成员」直达邮箱 / 角色邀请弹窗；页面快捷操作保留在「我的」。当前 Team 和下拉中的 Team 展示已加入成员人数（不含待接受或已移除成员），随成员状态更新。

## 全部闪念（2026-10-07）

全部闪念采用跨月份的单条记录索引，按记录时间分组，提供正文/金额搜索、分类、日期范围、排序和加载更多。真实记录计数取代静态月度文件数量。仅保留日程、待办、灵感、记账、其他五个类型 tab，按此顺序排列。灵感、记账、其他可通过轻量弹窗查看和编辑；原始捕获保留，保存后同步首页与详情，支持未保存保护、存储失败回滚及跨标签冲突检测。记录保存在 `eureka:thoughts:v1`，仅限当前浏览器个人空间；记账暂只支持人民币，收入不计入首页今日支出。

日程与待办继续读取 `PersonalAssets` 的同一记录，闪念中显示摘要、来源和业务时间，点击条目弹窗查看，行内编辑直接弹窗，只有「详情」进入原完整详情；返回保留筛选。待办可在行首直接勾选完成 / 重新打开。闪念工具栏撤去新建日程，「记录闪念」打开下载 App / 购买设备引导弹窗，另保留跳转日历入口；Ask Agent 引用当前筛选记录，沿用本地模拟边界。测试：`thoughts-model.cjs`、`thoughts.spec.ts`。

个人版与团队版的「我的 → 个人设置」共用账户、语言、自动摘要与声纹功能页，使用紧凑字号和间距。偏好随同一账号保留，团队普通成员也可修改；关闭返回当前空间首页。空间管理的「通用设置」改为「空间设置」，继续仅管理员管理当前团队属性。

团队订阅的席位用量下方提供主按钮「增加席位」，默认新增一席并沿用确认费用与模拟支付流程；「管理席位」保留减席等操作。Credits 的购买按钮移至可用余额下方。空间设置卡片随主内容区展开，名称/地区宽屏双列、窄屏单列，退出说明与按钮同步自适应。入口和响应式回归：`tests/e2e/team-management-entry.spec.ts`。

Agent 面板共享 `assets/agent-panel.css`：统一个人首页、历史、日程与待办、联系人及团队的标题、消息、推荐提问和输入区。全部移除快速/深度模式切换，工具和发送保持同一行，小尺寸电脑采用紧凑布局。联系人移除双重焦点边框，历史首次打开从消息开头阅读。回归：`tests/e2e/agent-panel.spec.ts`。

Agent 标题栏进一步收紧为 64px，标题 16px、描述 11px；个人版和团队版均移除输入区底部的引用说明、快捷键提示及模拟文字占位，发送快捷键与引用能力保持。
