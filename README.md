# Eureka

EurekaMind 个人与团队工作台，使用 React + Next.js App Router + TypeScript + Tailwind CSS。原型基线和 PRD 保留在 `src/prototype/`，用于回归对照。

## 本地运行

```bash
npm install
npm run dev
```

访问 <http://localhost:3000>，进入登录 / 注册演示；完成后直接进入个人工作台首页，无用途问卷或信息收集步骤。

## React 工程

根入口提供原生 React 登录演示；`/workbench/` 承载个人与团队页面、弹窗和 Agent 面板，不再通过 iframe 进入业务界面。工作台沿用原型 CSS、SVG、文案与布局。认证页按新版截图调整表单布局，右侧以个人灵感、团队共识与 Agent 助力三个场景展示轻动效。PRD 地址保持 `/prototype/prd/index.html`。

基线版本为 `prototype-baseline-20261007`。组件、数据兼容、验收及服务边界说明见 [React 迁移记录](docs/react-migration.md)。

## 质量检查

```bash
npm run check       # ESLint、TypeScript、原型资源引用和模型测试
npm run build       # 生产构建
npm run test:e2e    # Playwright 浏览器测试（需先安装依赖）
```

原型自身的模型测试位于 `src/prototype/one-to-one-reference/tests/`，覆盖联系人、应用数据筛选排序、编辑权限、团队数据隔离和导出行为。

## 目录约定

- `src/app/`：Next.js 工程入口和页面壳层
- `src/features/`：原生 React 页面、共享界面、hooks、类型及本地数据适配器
- `src/prototype/`：冻结原型、PRD、素材和原模型测试
- `scripts/`：原型资源准备、静态引用检查和测试入口
- `docs/prototype-import.json`：纳入仓库的原型文件校验清单
- `.github/workflows/ci.yml`：提交和 Pull Request 的自动检查

- `develop`：日常集成和下一轮迭代

## Team 工作空间演示（2026-10）

**2026-10-09 规则更新：**一个账号保留个人空间，可创建或加入多个 Team。每个工作区独立维护设置、成员、账单和一套权益，管理员付费；成员任务只消耗所属工作区权益。加入任一有效团队后个人权益冻结。仍不提供主动退出或解散。

全站共用 `eurekamind-agent` 身份，`src/features/agent/registry.js` 按场景配置数据 MCP 和 skill 的接入标识。个人对话共用会话存储，团队对话沿用授权与 Credits 模拟模型。历史入口位于各 Agent 窗口右上角，与新建会话并列；任务管理与侧栏历史列表撤下。真实 MCP、skill 和 Agentplatform 服务尚未接入。

当前规则测试见 `tests/e2e/single-team-agent.spec.ts` 及 native 测试。`src/prototype/one-to-one-reference` 与其模型测试为冻结历史基线，不代表本次产品规则。

从左上角工作空间菜单进入，账号保持统一：

- 个人空间：保留现有会议、闪念、联系人与 Agent。个人订阅独立于 Team，仍有有效 Team 时冻结。
- EurekaMind 产品团队：管理员场景，演示成员邀请/接受/撤销、角色管理、席位、账单、设备、Credits与空间设置。
- 普通成员场景使用产品团队的 Kevin 视角验证，只能访问授权资料。
- 工作空间邀请：已有 Team 也可接受其他工作区邀请，同一工作区不可重复加入。
- 创建团队：方案 → 空间信息/席位/周期 → 模拟支付（支持失败重试）→ 开通/邀请成员。

团队与个人共用首页、开始录音入口，个人为「我的客户」、团队为「团队客户」。团队首页仅保留紧凑 Agent 团队简报和会议列表，会议按本人或获邀权限展示。闪念、日程、待办、灵感和记账只在个人工作区使用。团队工作区分组包含团队成员、设备查看（仅管理员）、空间设置及开放API调用；不设闪念一级入口。历史会话入口位于 Agent 窗口右上角，与新建会话并列，仅显示本人当前空间记录。任务管理与自动任务入口撤下，旧数据保留。Agent 支持引用资料、联网开关及拖拽调整宽度，不提供回答模式切换。默认团队包含私有及已明确邀请的示例录音；数量随日期样例变化，可见范围按当前授权计算，新建团队保持空态。

Team 只使用一种 Unlimited 席位；邀请占席，移除成员释放席位但不自动减账单；加席通过数量预览 → 费用确认 → 模拟支付 → 成功后才生效，支持失败重试、取消、待付恢复与幂等账单；减席与周期切换安排到下一账期，可通过「模拟下一账期」验证。管理员可以管理成员与设备元数据，但不会获得成员私有录音的访问权。设备支持手动录入 SN、型号并绑定成员账号：管理员和普通成员均只能绑定本人设备；重复 SN 拒绝，长数字与前导零按文本保留。原设备申请 / 发放入口已替换，历史设备保留。“绑定已有设备”打开下载 App / 购买设备双入口弹层，实际绑定在手机 App 内完成；Web 不再模拟直接改绑，切换空间不会改变账号绑定及团队共享资格。首页统一通过「上传」接收 m4a/mp3/wav/opus/flac/aac 音频，旧纪要 JSON 导入入口已撤下；会议详情仍支持导出演示 JSON。

EurekaMind 独立采用 Team Credits 共享池：所有成员的 Agent 会话及自动任务按输入/输出 token 模拟用量扣减，不按席位分配或按次固定扣费；与成员转写权益、个人空间 Credits 分别记账。额外购买包含套餐、订单、失败重试、取消、刷新继续支付、成功到账与下载账单，支付成功只发放一次。演示费率为每 1,000 输入 tokens = 1 Credit、每 1,000 输出 tokens = 2 Credits，保留三位小数；生产须使用模型实际返回用量及服务端费率。团队页面底部可切换演示成员视角验证权限。该入口仅用于本地原型测试，不代表实际身份切换或服务端授权。

数据模型：`assets/workspace-model.js`；界面：`assets/workspace-ui.js` / `.css`。新增状态保存在 localStorage 的 `eureka:workspaces:v2` 中，不覆盖旧团队原型或个人会议存储。付款、邀请邮件、设备通信和 Agent 均为本地模拟；下载的账单不是有效发票。所有价格为 EurekaMind 演示假设。生产环境仍需接入身份认证、租户级授权、支付和设备服务。

参考：实际访问 [Plaud Web](https://web.plaud.ai/) 与 [团队方案页面](https://web.plaud.ai/member/workspace/plan?from=profile_dropdown)，并核对 [工作空间](https://support.plaud.ai/hc/en-us/articles/57744144794393-What-is-a-workspace)、[席位规则](https://support.plaud.ai/hc/en-us/articles/57744114159641-What-is-a-seat)、[设备绑定](https://support.plaud.ai/hc/en-us/articles/57674058082841-Device-management) 官方说明。参考其账号与空间边界，UI 沿用 EurekaMind 现有设计。

## 个人日程与待办、订阅（2026-10-07）

个人侧栏「日程与待办」位于联系人上方，与首页、全部闪念共用记录。日、周、月支持同一时刻的两类条目、跨日显示、日期跳转、详情与编辑。新建使用轻量弹窗，保存后回到日历；日 / 周 / 月均有行内编辑入口，直接弹窗修改；未保存退出有保护。日历不提供搜索和状态筛选。右侧 Ask Agent 采用共享图标，支持当前日期范围的本地分析、来源跳转，以及确认草稿后创建日程或待办；桌面并排并可拖宽，窄屏纵向适配。个人设置移除日程与待办提醒模块，单条记录仍保存提醒字段。

个人订阅按移动端参考演示标准版 400 分钟、Pro 月付 $17.99 / 年付 $99.99；Pro 每月 5,000 Credits 与 99,999 分钟。订单支持模拟成功、失败重试、取消、刷新续付、下载 USD 账单、取消自动续费和本浏览器恢复购买。付款成功才更新个人权益且一次入账，不改 Team。首期 Credits 可验证到账；后续月度刷新与真实自动扣款需后端服务。切换月/年套餐按全额重新起算演示，正式差价规则待确认。

新增模型 `personal-subscription-model.js` 与 `personal-calendar-subscription.spec.ts` 覆盖订单幂等、存储失败、日历/弹窗/Agent 布局和各屏幕尺寸；PRD 的个人日程、个人订阅与验收章节已同步配图。

## 团队版数据规则澄清（2026-10-09）

最新需求以 [PRD 内容源](src/prototype/prd/content.json) revision `prd-20261010-01` 为准：设备由本人管理并固定绑定一个工作区；加入团队不自动共享，会议共享开关默认关闭，闪念不提供团队共享，成员主动选择接收人后开启。被管理员移除后，设备绑定及本人数据保留，团队保留此前已共享历史，后续增量不再共享。仍不支持成员主动退出。

联系人即客户信息，仅在同一成员、同一工作区的不同 channel 间归一、去重，优先采用获授权且匹配的 CRM 已有数据；CRM 无对应数据时再做该成员内的多源归一。不同成员之间不归一、不去重；如需跨成员处理，由推送后的 CRM 管理员或 CRM 侧负责。

已同步实际运行的 React 原型：团队设备页仅管理员可看元数据，无解绑、模拟同步或内容设置；当前工作区内容权限覆盖硬件、软件录音、上传及闪念，两个开关默认关闭，开启需指定接收成员。我的客户新增仅支持手动录入与 CRM 系统导入；其他渠道由 Agent 接入，已核实身份与 CRM 字段优先规则保留，冲突候选内部留存，页面不展示来源归一模块或 CRM 导出，不做跨成员合并。旧 HTML 对照基线保持冻结。

本地存储兼容升级保留账号原始数据与团队已共享历史，不自动补共享加入前数据；真实设备、CRM 查询和推送仍需服务接入。相关回归：`account-sharing-model.spec.ts`、`account-sharing-ui.spec.ts`。

### 2026-10-09 默认私有与工作区隔离
团队工作区内的录音、转录、上传、笔记、闪念和联系人默认私有；管理员角色不增加内容权限。设备仅本人可解绑，管理员查看元数据。内容权限位于空间设置，两个开关默认关闭，开启时逐成员选择查看／编辑，不补发历史。关闭只停止增量，既有内容可单独撤销授权。切换视图不会移动或合并内容，也不改变设备保存位置。

团队首页展示会议简报、会议列表和新建笔记；闪念及日程与待办仅在个人工作区使用。联系人按成员与工作区隔离、同一范围内 CRM 优先；客户通过当前工作区本人的共享开关向团队开放查看，关闭立即收回；资料由所属成员维护，不跨成员归一去重。管理员移除成员时保留此前明确共享的历史与原接收人权限，停止增量并保留原工作区绑定，由本人换绑才能向新工作区录制同步。旧版自动公开的设备内容保留原记录、收回自动广泛授权；明确邀请的授权保留。

设计与验收边界见 `docs/private-workspaces-design.md`。所有分享、设备同步及 CRM 导入仍为本地原型，非真实服务联通。

### 多工作区与当前权益
取消首个 Team 的访问过滤，菜单可切换所有已加入的团队，并继续创建／加入。每个 Team 维护独立成员、设置、账单、转写用量和 Credits；在某区执行的任务仅记入该区，不向个人或其他团队回退扣费。设备保存空间独立于视图，每个 Team 分别控制共享。

个人与团队按当前工作区独立使用套餐。加入、移除或续费 Team 不阻止个人录音、AI 与订阅操作；界面只展示套餐和实际剩余额度。旧版暂停记录一次性补偿已累计的时间，此后不再因成员关系暂停个人权益。

回归：`multi-workspace-model.spec.ts`、`multi-workspace-ui.spec.ts`。支付、转写与 Agent 仍为本地模拟。

我的客户原型（2026-10-09）：支持企业／自然人、来源和创建日期筛选，添加仅手动录入／CRM 演示目录导入；详情以会议跟进、双方待办和来源画像为主。创建跟进复用日程弹窗，按账号与工作区隔离保存。日程没有未安排待办时隐藏空白区域。

### 团队只读及采集归属
到期或取消生效后，团队历史内容可检索，手动创建、编辑、上传与 AI 不可用。设备仍绑定账号，新硬件录音按录制时绑定工作区同步为原始音频，暂停转录和 AI，恢复后进入待处理队列。设备绑定工作区决定硬件新录音归属，软件录音与上传归发起工作区，切换不移动或合并历史内容。团队开始录音复用个人的权限流程。硬件通信及 AI 处理仍为本地原型模拟。

最新确认：硬件设备固定绑定工作区，切换页面不换绑，必须本人明确解绑再绑定；A 期间录音及离线补传仍归 A。账号菜单「我的设备」管理本人绑定，团队设备查看保持管理员只看元数据。当前团队共享逐成员提供查看／编辑，编辑不含删除或转授权，且不能绕过到期只读。

最新归属规则：设备会议跟随录制时绑定工作区，闪念始终保存在本人个人区且不参与团队共享。旧团队闪念按所有者迁回，保留个人已编辑版本；个人区按自己的套餐处理闪念，不改扣团队权益。

客户最新规则：个人入口为「我的客户」，团队为「团队客户」。客户只在创建工作区展示，切换空间不携带；团队列表聚合本人及其他成员共享的客户，标记所属成员并支持筛选。来源统一为手动录入、CRM、Agent 创建。客户开关默认关闭，开启向全体有效成员开放已有及未来客户查看，关闭即时收回但不影响查看他人共享客户。旧快照分享停用，旧快照仅所有者可读写。移除成员收回其客户共享；会议历史仍按原获邀权限保留。

Team 价格按本次截图更新：月付原价 $35、首月 $28 / 席位；年付原价 $300、首年 $240 / 席位（分别折合 $25 / $20 每月）。首次 8 折，年付相较月付约省 29%，税费另计；续费与新增席位按原价、现有整周期演示规则计费，历史账单保留原币种与金额。个人 Pro 与 Credits 套餐不变。

设备绑定确认：账号标识设备所有者，Personal／Team Workspace 才是设备实际绑定对象。硬件会议录音按录制时绑定保存与计量；App 切换只改视图，不换绑。软件录音、上传按发起工作区处理。换目标需本人明确解绑再绑定，历史与离线录音不迁移；闪念沿用仅个人保留的独立规则。
