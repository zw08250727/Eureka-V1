# 国内个人／企业连接器目录与系统详情

## 范围与责任

- 规则：CONNECT-01、MARKET-01、ENTERPRISE-01、FE-01／02／08／10、UI-TYPE-02。
- 国内个人／团队使用原工作台连接器入口；国内企业使用独立企业工作台入口和独立存储键。海外沿用原目录与账号域，复用卡片和详情组件。主责按 `spc/modules.json`：国内高璐璐，海外李鹤飞；共享组件需关联 UI 负责人张伟评审。此记录是本地实施证据，不代表人工评审或发布批准。
- 不修改冻结原型、生成 CSS 或旧连接器数据。存量目录读取时补充新增的腾讯会议系统卡片，写入需用户实际操作。

## 交付

- React 入口：`/cn/workbench/?view=connectors`、`/cn/enterprise/` → “连接器”；海外入口 `/global/workbench/?view=connectors` 用于回归。
- 列表分系统和自定义两区。国内系统卡片为钉钉、飞书、腾讯会议；自定义区保留 URL／JSON 配置与编辑、删除。当前目录不展示搜索栏。
- 系统详情复用 `ReferenceDialog`；未连接时有连接入口和推荐任务，已连接时显示去使用、断开、技能、状态与连接时间。断开需确认，后续状态立即不可用，原有内容保留。
- 连接按钮优先使用已配置的公开应用 ID 和回调 URI 构造官方授权地址；缺少配置时打开官方登录入口。打开页面不更改本地连接状态。`?review=1` 提供可见的评审模拟成功操作，仅在当前页面预览已连接视觉；刷新即恢复，不能作为真实授权证据。
- 企业身份读写在 `enterprise:<code>:<identity>:connectors:v1`，个人／团队保留原 `eureka:connectors:native:v1:<space>:<actor>`。均经 `marketStorage`；企业修改前重检独立会话，个人／团队重检空间权限和存储快照。

## 真实授权接入条件

| 平台 | 官方授权入口 | 前端公开配置 | 服务端仍需完成 |
| --- | --- | --- | --- |
| 飞书 | `https://accounts.feishu.cn/open-apis/authen/v1/authorize` | `NEXT_PUBLIC_FEISHU_CLIENT_ID`、`NEXT_PUBLIC_FEISHU_REDIRECT_URI` | 回调 state 校验、授权码换令牌、权限与主体绑定、撤权及令牌刷新 |
| 钉钉 | `https://login.dingtalk.com/oauth2/auth` | `NEXT_PUBLIC_DINGTALK_CLIENT_ID`、`NEXT_PUBLIC_DINGTALK_REDIRECT_URI` | 同上，且确认委托权限 scope |
| 腾讯会议 | `https://meeting.tencent.com/marketplace/authorize.html` | `NEXT_PUBLIC_TENCENT_MEETING_CORP_ID`、`NEXT_PUBLIC_TENCENT_MEETING_SDK_ID`、`NEXT_PUBLIC_TENCENT_MEETING_REDIRECT_URI` | 同上，且校验企业管理员授权与会议访问范围 |

这三个回调 URI 须在各平台应用后台预先注册并指向服务端。不能把 Client Secret、Access Token 或刷新令牌写进静态前端配置。服务端完成兑换、核验、加密保存和撤权同步之后，才能用受信接口更新“已连接”；浏览器获得授权码或打开登录页均不足以认定成功。官方依据：[飞书授权说明](https://open.feishu.cn/document/server-docs/authentication-management/access-token/obtain-oauth-code)、[钉钉浏览器授权](https://opensource.dingtalk.com/developerpedia/docs/develop/permission/token/browser/get_user_app_token_browser/)、[腾讯会议 OAuth2.0](https://cloud.tencent.com/document/product/1095/51257)。

## 验收与回滚

- Given 国内个人或企业账号打开连接器，When 查看目录，Then 三张系统卡片和自定义入口可见；企业与个人数据不互读。
- Given 未连接，When 打开详情并点击连接，Then 进入官方页面且仍未连接；评审模式可单独模拟成功以检查视觉。
- Given 已连接，When 打开详情、断开并确认，Then 状态变为未连接且既有内容不删；切换工作区或账号不复用授权。
- Given 团队到期或身份变化，When 保存，Then 拒绝操作并保留原状态。
- 回滚：撤回本次 React/CSS/配置改动；新增数据键不删除、不迁移。`market-20261016-connectors-01` 为国内配置版本。
