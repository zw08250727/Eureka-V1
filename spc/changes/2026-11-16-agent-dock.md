# UI-AGENT-DOCK-01 · Agent 与顶栏并列

来源：2026-11-16 用户截图及明确要求。适用于国内／海外、个人／团队所有可展开收起的 Agent 场景；架构／UI 主责张伟，Agent 主责高璐璐，人工评审状态待核对。

- 桌面（761px 起）展开 Agent 后，右侧对话面板从应用顶部延伸到视口底部，顶栏常驻入口排列在面板左侧；收起时恢复顶栏宽度。
- 拖动宽度时顶栏同步让位。窄内容区允许顶栏换行，商城入口保留原图标、文案与操作；移动端沿用现有单列布局。
- 复用 ReferenceShell、既有面板及宽度控制，在外壳中集中适配几何位置；不复制市场页面、不改冻结样式源。面板状态、业务动作、会话、权限、计费与存储契约保持现有职责。
- 关联 FE-06／07／09／10、UI-TYPE-02、MARKET-01；仅展示布局变化，不修改业务基线。
- 验收：两市场 1440×900、1080×680 的首页、闪念、日程、通讯录、个人／团队会议、团队首页展开→顶部对齐→输入框可见→常驻入口不重叠→宽度调整→收起恢复；另核对移动端与历史会话。
- 自动回归见 `tests/e2e/agent-dock.spec.ts`。撤销本轮外壳 Hook、CSS 导入与桌面对齐适配即可回滚，不涉及用户数据。

实施计划与结果：先检查各场景面板和冻结 CSS 的定位约束；再增加共享停靠 Hook 与作用域样式、停用桌面旧滚动对齐；最后执行 check、build 及跨市场浏览器回归。外壳和几何 Hook 为展示层；原 useAgentLayout 仅调整桌面滚动，保留历史会话聚焦和移动端对齐。未触及业务模型。

修改文件：`src/features/reference/use-shell-agent-dock.ts`、`agent-dock.css`、`shell.tsx`、`use-agent-layout.ts`（后面三项均在同目录），以及上述回归测试和本记录。

验证结果：`npm run check`、`npm run build` 通过；Chrome 下 `agent-dock.spec.ts`、`guest-auth.spec.ts`、`single-team-agent.spec.ts --workers=2` 40 项通过。补充 768px 与展开状态下 390px→桌面往返后，最终停靠专项共 6 项通过，覆盖两市场八场景；截图位于 `test-results/agent-dock-{cn,global}-{1440,1080,768}.png`。初次并发运行出现 30 秒测试总时限不足，已为包含多场景的专项设置 90 秒上限，并以 2 workers 完成回归。人工业务评审与发布不由自动化结果代签，本轮未提交或部署。
