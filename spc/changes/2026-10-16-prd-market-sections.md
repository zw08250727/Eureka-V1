# PRD 1.6：国内／海外专项独立维护

## 目标与范围

用户要求把国内与海外业务逻辑、实现方式不同的部分直接拆出，以便各市场 PM 迭代。沿用上轮未发布的 PRD 1.5 修订；新版本 `prd-20261016-market-sections-02`，共 51 章，原有 38 章锚点保留。

PRD-MARKET-01：新增国内 6 章、海外 7 章，分别覆盖认证、订阅、积分、支付、连接器／Agent、UI／客户端，以及海外语言化。每章明确主责、个人／团队范围、业务要求、当前实现、未接服务、依赖和专项验收。详细参数从共用章节迁出，共用契约只保留账号域、归属、权限、状态及幂等；一个网站和内容源，独立章节编辑，不复制完整工程或另建产品 HTML。

国内订阅／积分唐娅，海外订阅／语言化鹤飞；连接器国内高璐璐、海外李鹤飞；Agent 高璐璐；UI 张伟。日程佳音、通讯录杨斌协作共用规则；账号、海外 Credits、支付等未指派部分仍待认领，不重复询问或虚构确认。

## 核对发现与处理

| 差异 | 实现依据 | 文档处理 |
| --- | --- | --- |
| 国内版本卡片、验证码和企业独立页；海外直接覆盖层 | auth、enterprise、market workbench | 独立 cn-auth／global-auth，共用 auth 保留门禁 |
| 国内 DomesticMembership；海外 PersonalBilling | spaces/billing.tsx | 价格、加时包、组件与工作区边界独立维护 |
| 国内个人单次购买；海外 renew=true 且可调整 | model/subscription.js | 修正上轮笼统的续费口径；团队续费另按共享模型 |
| 国内月会员 grant 补发；海外 refresh 不执行 | model/subscription.js | 海外月赠为产品目标／待服务实现，不虚称等价 |
| 国内批次有效期／2 小时充值窗；海外累计余额 | credit-ledger.ts、core.js | 分开当前实现与正式结算需求，不改任何余额 |
| 国内反馈北京时间、签到本地时间；海外按本地时区 | account/rewards.ts | 记录待决策，不静默统一 |
| 国内团队 USD 演示价格与微信／支付宝配置 | cn.json | 正式币种／渠道兼容性列为待确认 |
| 海外不同商品与团队支付资料渠道不一致 | global.json、billing.tsx | 按商品和入口核对，不把配置当真实接通 |

规则依赖 MARKET-01、ACCOUNT-01、RIGHTS-01、ASYNC-01、CONNECT-01、SHARE-01、EXPIRE-01 保持；不改业务源码、价格配置、授权或存储，不迁移用户数据。新增文档内 CN／GLOBAL 规则仅组织专项，不覆盖 SPC 已确认规则。

## 维护与验证

模块清单补充市场章节映射，PRD 维护说明和 workflow 写清共同规则联合评审、单市场章节独立迭代和按稳定 ID 合并。旧草稿保留原存储，不自动迁移；已有不兼容结构提示继续适用。

验证覆盖 JSON、唯一锚点、表格列数、模块章节／来源、AC 编号及配图路径；运行 `npm run check`、`npm run build`；Chrome 核对两地专区目录、关键词搜索、独立编辑与其他章节不变、JSON／Markdown 导出、手机阅读和旧锚点。结果均通过：51 章含国内 6／海外 7 个专项、78 个 AC 引用可解析；两地订阅章节分别修改／保存／刷新后另一市场正文不变；JSON 与 Markdown 导出、重新导入、4 个流程及全部引用配图正常，390／768／1080／1440px 无整页横向溢出，旧草稿存储未被覆盖，浏览器无脚本错误。桌面国内／海外专项页面已截图核对。
