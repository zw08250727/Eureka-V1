# 手机通讯录导入改为 App 引导

来源：用户标注手机联系人选择、示例预览与合并说明，要求引导到手机 App 操作。主责为通讯录／个人资产，负责人及联合评审人待认领；关联账号／工作区模块。国内／海外、个人／团队同步，独立企业域不涉及。

## CONTACT-PHONE-01

添加联系人保留“手动创建”和“手机通讯录导入”两个标签。手机标签展示“请在手机 App 中导入通讯录”，提示使用与当前网页相同的账号登录、选择对应个人／团队工作区、授权并选择联系人导入。移除示例目录、选择器、预览、隐藏数据、CRM 合并说明及“确认导入”按钮，仅保留“知道了”关闭操作。此规则替代 CONTACT-ADD-01 中网页手机示例导入行为，不改变既有手机来源记录或底层跨来源模型。

复用 ContactDialog 和现有弹窗关闭、焦点及按钮样式；模块 CSS 使用语义字号和颜色。无新组件、依赖、下载地址、二维码或 App 跳转协议；不虚构网页读取手机或跨设备同步成功。上游为标签选择，下游仅关闭弹窗；引导模式阻断表单提交，不调用 onSave、不写存储。手动创建、编辑、备注与失败保留输入沿用原流程。市场隔离、共享与只读权限不变，遵守 MARKET-01、SPACE-01、ACCESS-01、SHARE-01 及 FE-01～FE-10。无数据迁移、删除或架构例外。

## 验收

Given 两地个人／团队，When 切换手机标签，Then 显示 App 引导，无联系人选择、预览或提交按钮；点击“知道了”、Esc 和遮罩可关闭，焦点返回。重复查看与关闭、触发表单提交均不新增记录。切回手动创建仍可正常保存；390／768／1080／1440px 内容无溢出、按钮可见。

检查：`npm run check`、`npm run build` 通过；两地联系人方法与布局 4 项通过，团队联系人共享 1 项通过。旧共享测试使用手动创建准备数据，不再依赖已取消的网页手机导入；角色切换改用既有 actor 路由，避免依赖普通界面不显示的评审选择器。截图位于 `test-results/contact-add/`，已查看国内桌面、海外团队窄屏引导。当前为本地修改，人工验收待用户。回滚只撤回本次组件、样式及用例调整，不影响用户记录。
