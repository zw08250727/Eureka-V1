# 两地通讯录、日历与首页统一发布

用户于本轮明确要求“以上，全部发布”。本次按最终验收版本统一发布国内／海外，覆盖个人／团队共用功能；此前变更记录中的“本地交付／未发布”描述为各轮实施状态，本记录承接统一发布授权。

## 最终范围

- 手机通讯录导入改为手机 App 操作指引，不在网页写入示例联系人。
- 日程与待办详情收紧卡片、字段和模块间距；全部闪念列表去掉独立创建时刻，保留实际区间／截止时间，并统一共享、编辑、详情入口。
- 日视图来源／成员跟随标题，操作常驻；周／月来源在标题同一行右侧，截断可悬停查看，操作在右下角 hover／focus 显示，触屏可用。UI-CALENDAR-11 替代 UI-CALENDAR-06 的早期布局。
- 个人／团队首页去除重复斜箭头，保留文字导航和会议依据展开控件。
- 个人首页采用一个紧凑实心“帮我安排”主按钮和一个无边框“全部闪念”文字按钮；国内黑色、海外主题靛蓝。UI-PERSONAL-ACTION-12 替代 UI-PERSONAL-LINK-10 的双描边方案。

此前已上线的 CRM 导入 Tab 移除、通讯录筛选标签及核实勾选项移除、联系人卡片标签／日期／共享位置修改继续保留。没有资料删除、历史数据迁移、账号或权限变更。

## 验证与发布方式

`npm run check`、`npm run build` 及 `git diff --check` 通过。`PLAYWRIGHT_CHANNEL=chrome npm run test:release` 通过市场模型及 224 项浏览器验收；通讯录导入引导／适配及共享权限 5 项专项检查通过。各 UI 变更已完成两地 390／768／1080／1440px 的截图与操作核对，细节见同日各项记录。

沿用现有 Pages workflow 的市场发布验收入口（workflow_dispatch 的 skip_browser_acceptance=true 实际运行 test:release），构建包含 `/Eureka-V1` 前缀的静态站，发布同一份 CN／global 工程。部署后核对 workflow 状态、两地登录／路由基础链路及本次 UI 生效状态。模块负责人仍待认领；本记录不虚构人工评审签署。

回滚可将本发布提交 revert 后重新部署；不需要数据回滚。
