# UI-MEETING-CAPTURE-01 · 两地会议录制交互原型

## 目标与归属

2026-11-16 用户要求：在首页、侧栏现有「开始录音」入口增加模式选择；原软件录音流程保留；新增会议屏幕和音频／仅音频、麦克风设置、全屏／应用窗口选择；复用录制中控制与转写、总结；视频记录在原播放器位置回放；列表区分 APP、Web、硬件、视频录制、音频录制图标。用户明确确认「完成交互原型，沿用当前工程的模拟方式」。

- 适用国内、海外，个人、团队；企业独立域不扩展。市场维持独立账号与存储，同一市场内个人／团队共用账号。
- 会议模块主责待认领；UI／架构张伟；依赖方为账号／权限（待认领）、日程（佳音）、Agent（高璐璐）。人工联合评审待相关负责人确认，自动测试不代签。
- 遵守 MARKET-01、SPACE-01、ACCESS-01、SHARE-01、ASYNC-01、EXPIRE-01、AUTH-GUEST-01、FE-01～10、UI-TYPE-02。新增 UI-MEETING-CAPTURE-01 为本轮交互记录，不变更共享业务基线或定价、配额、共享权。
- 上游：当前市场／账号／工作区／关联日程，录制方式、麦克风、转写语言和选定范围。下游：原会议保存链路，增加可选 capture 元数据与显式示例媒体地址；列表来源、详情播放与转写定位使用同一会议 ID。

## 交互与组件

入口为现有 `/cn/workbench/`、`/global/workbench/` 首页及侧栏「开始录音」。两地共用流程，国内／海外的文字和主题继续服从市场 UI 规范，市场不是语言。录制页、会议详情仍在现有 React 路由。

1. 「选择录制模式」：开始录音／录制会议。关闭、Esc 回到原页面，不生成会议。
2. 开始录音：进入现有录音权限说明及模拟授权，随后进入既有录制页；不跳过原有用户设置。
3. 录制会议：默认「屏幕和音频」，可切换「仅音频」；麦克风默认开启，可选择默认／内置／耳机，关闭后仅保留电脑声音；支持转写语言设置。
4. 屏幕和音频：进入「选择要录制的内容」，选择全屏或应用窗口。未选择时开始按钮禁用；切换页签清空范围选择；返回设置保留麦克风和语言配置。确认后进入录制页。仅音频直接进入录制页。
5. 录制中保留原暂停、继续、放弃、标记、结束和查看会议操作，仅增加来源／范围信息。结束保存后，转写与 AI 总结继续采用已有固定模拟内容。
6. 视频记录：原音频播放器位置改为原生视频播放器，支持播放／暂停、进度、全屏、倍速及前后 15 秒；转写段落和标记共用当前媒体定位，不同时挂载隐藏音频。仅音频仍用原音频控件。
7. 列表、详情标题及详情左侧文件列表使用共用来源图标。APP 用手机、Web 用浏览器与麦克风、硬件保留环境／通话 SVG、视频用摄像机、会议音频用显示器声波。来源文字和可访问名称一起区分，上传保持文件图标。

复用 ReferenceDialog、Select、Icon、RecordingPermission、RecordingPage、DomesticAudioPlayer、MeetingPage、marketStorage 和 appUrl。新增 RecordingLauncher 负责模式／设置／范围状态，MeetingVideoPlayer 负责视频呈现，capture.ts 负责可选元数据与来源映射，CSS Modules 限定样式。基础 UI 不依赖业务模型；没有新增检查例外或设计变量。原录制页与详情超过 500 行，本轮仅接入小范围数据和播放器分支，新流程和视频控件已拆出，避免重写原编辑、分享和权限逻辑。

## 原型边界与来源

参考用户截图及 [Notta bot-free recording 文档](https://support.notta.ai/hc/en-us/articles/53147900611867-Bot-free-recording-for-Zoom-meetings)。仅借鉴模式、麦克风、范围选择和回放交互；不沿用截图中划掉的「无机器人」标题，不宣称当前 Web 工程具有其桌面系统采集能力。

窗口列表为固定原型选项，不枚举真实应用，不调用 getDisplayMedia／getUserMedia，不采集用户桌面、麦克风或真实会议。新增示例视频由 `scripts/generate-meeting-capture-demo.mjs` 使用原创画布内容及工程既有 meeting-demo.wav 合成；本地播放器真实可操作。仅新模拟会议写入显式示例媒体 URL，历史无媒体记录不补示例、不迁移存储。

## 状态、权限与恢复

- 无选择：禁用开始；返回保留设置；关闭和 Esc 取消；选择区域支持键盘方向键、Home／End 和按钮激活。
- 加载／失败：视频加载及失败沿用媒体事件状态，提供重新加载；缺失或非法 URL 展示无视频，不替换音频或任意示例。重复结束沿用稳定 recordingId 与保存锁，不重复创建或扣配额。
- 存储失败：保留录制页、显示错误，不显示保存成功，可重试。放弃不创建会议，保留既有离开保护和控制语义。
- 未登录继续走原登录续接工具逻辑；开始、结束均沿用工作区有效性校验。到期团队只读；撤权拒绝写入。
- Launcher 在入口锁定工作区、账号，确认时重检；录制路由与保存继续使用原市场适配层和锁定的工作区／关联日程，不因浮层内选择改变归属。
- 回滚：撤销 Launcher 接入、capture 可选字段读写和视频分支，恢复旧来源图标即可；不删除或自动迁移任何用户资料。
