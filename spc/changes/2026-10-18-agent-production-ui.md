# Agent 充值与执行过程交互修订

状态：按用户明确的四项修改实施，本地产品交互；不代表支付、AgentPlatform 或 MCP 生产服务已接通。
主责：Agent 高璐璐；UI 张伟；国内 Credits 唐娅；海外 Credits 待认领。适用国内／海外 × 个人／团队及所有现有 Agent 场景。

## 已确认范围与设计

1. Agent「充值 Credits」复用 AccountExperience 现有充值弹窗、套餐、币种、支付和关闭行为。个人与团队管理员可操作；普通成员只提示联系管理员，不发消息、不开放充值。预演复用同一组件，以独立内存 controller 完成订单演示，不写真实账本。
2. 正文保持既有字号。费用、异常与停止等系统信息使用 12px/18px 辅助文字；不足用语义警告色、提示图标和细分隔线，保证不是正文续写。只保留充值这一主要恢复操作。
3. 移除对话内「重新结算本轮」入口。最终回执已确认且到账足额、权益有效时，自动更新原 runId；禁止重发问题、重复扣费、跨市场或跨池。缺失回执继续待确认，不猜费用。预演到账／回执注入仅在评审工具，到账也自动恢复。
4. 过程 UI 参考 WorkBuddy 官方任务对话的阶段、可展开中间步骤及临时 MCP 状态。当前回答文字下方使用轻量动作行：图标、动作与对象、明确状态、展开箭头。详情展示已收到的 skill／MCP／文件事件，完成／停止／失败有各自语义，不展示 token、费率或内部参数。动态趣味文案作为行下辅助文字，完成即停止轮换；结束后只保留可折叠过程摘要。

参考：https://www.workbuddy.cn/docs/workbuddy/Conversation （查看执行过程／MCP 服务加载）；官方图：https://download.codebuddy.cn/web/docs/5fcc784577447f1c241564381c92e0dfeb888ff0/docs/static/conversation-exec-progress.DHoekDQp.png 。借鉴信息层级，不复制其用量／预计消耗显示。

## 实施职责

- 纯展示：共用 AgentUsageFeedback、AgentWaiting、作用域 CSS；正文组件只组合。
- 混合交互：CreditReviewProvider 管理隔离预演；AgentAccountPanel 复用现有弹窗并选择真实／内存 controller；AgentSettlementSync 根据本区有效余额和原最终回执恢复。
- 数据契约：类型化过程事件增加稳定 ID、kind、对象名和状态；demo-stream 只提供演示事件，不读取实际用户文件，不宣称外部服务调用已接通。
- 账务公式、平台实际用量来源、市场价格、成员权限不变。AGENT-CREDITS-04/05 更新为自动恢复与产品交互，旧手动恢复验收不再有效。

## 实施与验收计划

按恢复服务与弹窗适配 → 展示组件与事件 → 各场景接入 → PRD → 测试和截图的顺序交付。

- Given 不足提示，When 个人／管理员点击充值，Then 打开同一充值弹窗，币种及目标池正确；取消不产生扣费或新回答，支付失败可重试，成功自动更新原运行。
- Given 普通成员，Then 无充值与手动结算入口；管理员到账后恢复本人原运行。待回执／到期／撤权时不误结算。
- Given 预演充值与重复成功回调，Then 只改变模拟池，原账本字节不变，runId 结算一次。
- Given 流式 skill／MCP／文件事件，Then 文字下方内联展示，可键盘展开，停止后无迟到内容，纯文本不伪造工具步骤。
- Given 390／1080／1440宽度及减少动态效果，Then 提示与正文大小／颜色可区分、文本不溢出，原输入／停止可达。

恢复服务依赖实际最终回执与已确认到账；生产服务的原子结算、签名鉴权仍需后端联调。回滚本轮组件／自动恢复调用即可，不删除或迁移历史数据，不改冻结原型或架构白名单。测试不代替模块联合评审。

## 2026-10-19 普通链接入口

用户明确要求普通链接也显示入口。UI／Agent 沿用现有 ReviewFloatingButton 与评审弹窗，移除工作台外壳中对入口的 review=1 限制，覆盖两地个人／团队及各模块。配置默认关闭，Credits 预演仍需主动应用；其他业务页面的失败注入开关不变。同步 AGENT-CREDITS-05、UI 文案边界与 PRD；不新增组件、不改变账务或数据存储。回滚仅恢复入口条件和对应说明。

验收：普通链接各模块可见入口，两地个人／团队点击打开、Esc 关闭与焦点归还正常；未应用无模拟消息；390px／1440px 拖动、位置记忆与原 Agent 流式交互仍可用。沿用已有浏览器用例，将覆盖入口改为不带 review 参数。

结果：npm run check、npm run build 通过；普通链接入口、主动预演和未启用时的普通会话共 8 项 Chrome 用例通过。预演执行函数同步改为仅检查主动应用状态，避免入口显示后仍被 URL 参数阻断。
