# 国内版 UI 规范 · 百智

版本：1.1 / 2026-10-13，已确认。与 [公共 UI 规范](ui.md)、[组件规范](components.md) 一起执行。标记“目标”的值用于新增和后续改造，尚未全站实施。

## 视觉定位与主题

白色内容区、浅灰导航、深灰业务主按钮、亮蓝登录／链接／充值。避免大面积彩色背景、毛玻璃和无功能装饰。品牌蓝紫只用于已确认的品牌与会员积分场景。

现有主题：`src/features/markets/baizhi-theme.css`，仅国内 layout 引入；必须覆盖 body 浮层。以下语义名称为目标映射，现有别名可渐进兼容，不要求同时新增另一套实现。

| 语义 | 色值 | 当前依据／实施状态 |
| --- | --- | --- |
| surface-canvas | #FFFFFF | 已有白色内容区 |
| surface-sidebar | #F9F9F9 | --cn-sidebar |
| surface-subtle／input | #F2F3F5 | --market-soft／--cn-input |
| surface-selected | #EDEDED | --cn-selected |
| text-primary | #262626 | --text-primary／--market-ink |
| text-secondary | #595959 | --text-secondary |
| text-muted | #737373 | 已确认目标，替代小字号说明中的 #8C8C8C |
| border-default | #EBEBEB | --market-border |
| border-strong | #D9D9D9 | --border-strong |
| action-primary | #262626 | --cn-action |
| action-primary-hover | #111111 | --cn-action-hover |
| interaction／action-brand | #165DFF | --market-accent |
| interaction-hover | #0E42D2 | --cn-link-hover |
| auth-disabled | #ADC6FF | --cn-disabled，仅登录按钮 |

#8C8C8C 白底对比度约 3.36:1，不能用于正常小字号说明；#737373 白底约 4.74:1。检查实际背景，不以 token 数值推定所有组合均合格。弱分割线是装饰用途，必要的控件边界与焦点另需满足对比度要求。

## 字体、密度与布局

沿用中文字体栈：`"MiSans", "HarmonyOS Sans SC", "PingFang SC", "Microsoft YaHei", sans-serif`。不依赖新增远程字体。

| 用途 | 字号／行高 | 字重 |
| --- | --- | --- |
| 常规页面标题 | 24／32px | 600 |
| 首页主要标题 | 28／38px | 600 |
| 模块标题 | 18／26px | 600 |
| 卡片／弹窗分组标题 | 16／24px | 600 |
| 正文、表单、表格 | 14／22px | 400 |
| 按钮、导航、字段标签 | 14／20px | 500 |
| 辅助说明、时间、状态 | 12／18px | 400 |
| 会议／Agent 长正文 | 15／26px | 400 |
| 代码、技术标识 | 13／20px，等宽字体 | 400 |

间距使用 4／8／12／16／20／24／32／40／48px。图文 8px，表单项 20px，标准卡片内边距 24px，紧凑卡片 16px，模块间 24px。桌面内容边距 24px，窄屏 16px。侧栏沿用展开 272px／收起 76px；默认导航行 40px、触控 44px。更多尺寸以公共规范为唯一共用来源。

## 组件映射

| 组件 | 国内标准 |
| --- | --- |
| 普通主按钮 | 深灰底、白字、6px 圆角；默认高 40px |
| 登录／充值按钮 | 亮蓝底、白字、6–8px 圆角；触控 44px |
| 次按钮 | 白底、灰边、深灰文字；默认高 40px |
| Input／Select | 8px 圆角、默认高 40px；登录浅灰底且高 44px，业务表单可用白底边框 |
| 导航选中项 | 浅灰底、深灰文字、8px 圆角；保留文字与图标识别 |
| Tab | 亮蓝下划线，或浅灰轨道／白色选中块；同一组件保持一致 |
| 卡片 | 白底、1px 边框、目标 12px 圆角，默认无阴影 |
| 菜单 | 白底、目标 8px 圆角、轻阴影；默认菜单行 40px |
| Dialog | 公共尺寸 400／520／720px，目标圆角 16px；登录保留 20px 例外 |
| 积分／会员入口 | 保留轻蓝紫额度按钮与白色浮层，不把全部主按钮改为蓝色 |
| Agent | 白底文档式内容，发送按钮使用深灰业务主操作 |

状态色、焦点、键盘、弹窗关闭与反馈行为遵守公共规范。品牌色不能覆盖错误或危险状态。充值类统一使用 `credit-recharge-cta`，普通成员保持禁用及联系管理员说明。

## 场景边界

- 两地默认游客首页；国内登录为白底居中覆盖层，最大 520px、表单最大 400px，无右侧示意图。个人／团队和企业两个入口保留。
- 企业入口临时 toast“以线上为准”按现有 4.5 秒规则保留，不变为常驻提示。
- 游客不显示真实人物、余额和业务资料，不为复用布局而加载私人数据。
- 会议详情保留主体与右侧录音列表；个人／团队复用组件，权限依所属工作区派生。
- 积分入口只展示模型派生的身份、余额和奖励，不写死截图数字。团队充值权限不因视觉复用改变。
- 日期、金额从配置／记录读取；不能把历史 USD 价格只改为人民币符号。
