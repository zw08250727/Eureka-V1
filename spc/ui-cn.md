# 国内版 UI 规范 · 百智

版本：1.2 / 2026-10-13，已确认。与 [公共 UI 规范](ui.md)、[组件规范](components.md) 一起执行。UI-TYPE-02 字号已用于当前 React 界面；其他标记“目标”的值仍随模块渐进实施。

## 视觉定位与主题

白色内容区、浅灰导航、深灰业务主按钮、亮蓝登录／链接／充值。避免大面积彩色背景、毛玻璃和无功能装饰。品牌蓝紫只用于已确认的品牌与会员积分场景。

现有主题：`src/features/markets/baizhi-theme.css`，仅国内 layout 引入；必须覆盖 body 浮层。以下语义名称为目标映射，现有别名可渐进兼容，不要求同时新增另一套实现。

| 语义 | 色值 | 当前依据／实施状态 |
| --- | --- | --- |
| surface-canvas | #FFFFFF | 已有白色内容区 |
| surface-sidebar | #F9F9F9 | --cn-sidebar |
| surface-subtle／input | #F2F3F5 | --market-soft／--cn-input |
| surface-selected | #EDEDED | --cn-selected |
| text-primary | #262626 | --text-primary／--market-ink |
| text-secondary | #595959 | --text-secondary |
| text-muted | #737373 | 已确认目标，替代小字号说明中的 #8C8C8C |
| border-default | #EBEBEB | --market-border |

#8C8C8C 白底对比度约 3.36:1，不能用于正常小字号说明；#737373 白底约 4.74:1。检查实际背景，不以 token 数值推定所有组合均合格。弱分割线是装饰用途，必要的控件边界与焦点另需满足对比度要求。

沿用中文字体栈：`"MiSans", "HarmonyOS Sans SC", "PingFang SC", "Microsoft YaHei", sans-serif`。不依赖新增远程字体。

### UI-CN-AI-01 · 积分图标与动效

积分额度、升级、任务奖励统一使用 `AiIcon` SVG，24×24 viewBox、1.6px 圆端线条；按钮内 16px、顶部入口 20px、侧栏提示 24px，图文间距 8px。禁止再用字符星芒、闪电或菱形充当这些图标。品牌图标使用 `--ui-ai-primary`／`--ui-ai-secondary` 蓝紫配色；蓝色实心按钮内继承白色，禁用时继承灰色。

任务／充值／余额浮层插图复用 `AiRewardArtwork`，采用星芒、芯片轮廓与轨道节点，替代国内金币装饰；桌面 96px、移动端 64px。颜色来自语义主题，不修改海外插图。图形只作装饰，操作名称由按钮文字提供。

首次展示轻呼吸及节点闪烁 2.4 秒×2 次，轨道入场 4.8 秒后静止；悬停／键盘焦点轻抬升 600ms，节点反馈 1.2 秒，插图悬停轨道 1.6 秒。仅动画 transform／opacity，不循环旋转整张卡片、不扩大控件或闪动文字。`prefers-reduced-motion: reduce` 和禁用按钮关闭图标动画，保留可见图形与焦点。

### UI-SELECT-01 国内映射

Select鼠标展开保留1px `--ui-border`（#EBEBEB），不叠加蓝色外环；选中项用#F2F3F5背景、#262626文字和勾选图标。仅键盘活动位置使用#165DFF单层2px焦点线，触发器与选项不同时描边。其他控件的键盘焦点保持可见。

## 场景边界

- AUTH-UI-04／AUTH-UI-05：国内先展示个人／团队、企业双卡片（同层级）；个人／团队在当前页登录，企业导航至独立企业游客工作台并直接弹出企业认证。个人／团队为百智品牌；企业弹窗为百销文字品牌，不复用百智Logo，先企业代码再企业成员手机号／邮箱。弹窗最大520px、内边距40px（窄屏24px），无侧面宣传区，不在表单内切换版本。返回回到国内版本卡片，企业关闭或 Esc 留在企业游客工作台，可再次打开企业认证。背景按确认截图保留登录后查看、首页、开始录音、知识库、AI 专家·技能·连接器、历史任务及未登录账号；顶部“个人AI工作台”为来源界面文案，不代表复用个人账号域。
- 企业代码 bairong 定位百融智能；手机号／邮箱、更换企业与返回依据 2026-10-13 线上核对结果，移除原临时 toast。独立页面不再展示个人／企业切换 Tab。
- 首页今日简报待办列表为 12／18px，小字号保留原有点击区域；其他正文和海外待办保持原尺度。
- 游客不显示真实人物、余额和业务资料，不为复用布局而加载私人数据。
- 会议详情保留主体与右侧录音列表；个人／团队复用组件，权限依所属工作区派生。
- 积分入口只展示模型派生的身份、余额和奖励，不写死截图数字。团队充值权限不因视觉复用改变。
- UI-CN-POINTS-02：个人账户浮层宽300px（窄屏不超过视口减24px）、内边距10px、圆角12px。保留积分卡片的蓝紫渐变进度条、1px渐变边框、白色内容区和充值／签到双按钮；卡片内边距12px，奖励28／34px，余额14／20px，进度及说明12／18px。按钮桌面36px、窄屏44px；不使用阴影放大卡片。卡片随浮层收紧，与菜单保持8px间隔；顶部积分浮层和海外样式保持各自规范。
- 日期、金额从配置／记录读取；不能把历史 USD 价格只改为人民币符号。

## 验收和来源

覆盖 390／768／1080／1440px，游客及登录后、个人及相关团队角色、登录／充值／会员浮层、菜单焦点、错误及只读状态。主题变化需同时验证海外未受影响。

沿用 [国内视觉对照](../docs/baizhi-visual-reference.md) 的 2026-10-12 颜色证据；该历史记录中的分栏登录布局已由 AUTH-UI-01 替代。新增字号、尺寸、辅助文字色为本次确认的工程标准，不声称来自线上逐项测量。未重新核验线上全部页面。

### UI-CN-ACCOUNT-03 · 积分、会员与设置

积分任务、充值、订单浮层及个人／团队设置共用黑灰文字层级：标题与金额#262626、正文#595959、辅助说明#737373。蓝色只承担交互／进度／选中标记，奖励数字不再使用警告橙或旧蓝灰色。保留AI插图与UI-CN-POINTS-02账户签到卡片。

弹窗标题18/26px、分区16/24px、卡片14/22px、正文及表单14/22px、摘要和辅助说明12/18px；余额和套餐积分24/32px、价格20/28px。会员页标题22/30px。卡片圆角12px、中性1px边框、无常驻描边阴影；设置内容边距24px（窄屏16px）、分类卡片间距16px，不在网格子项重复叠加外边距。选中和输入焦点遵守UI-FOCUS-02，移动控件不低于44px。

### UI-TYPE-02 · 全局文字层级补充（2026-10-13）

公共语义字号由 `ui-foundations.css` 定义，当前 React 界面通过 `market-workbench.css` 与 `market-typography.css` 映射，body浮层同样继承。一级页面22/30px、二级分区16/24px、三级卡片14/22px，标题600字重；首页欢迎和认证24/32px，弹窗标题18/26px、内部依次16/24与14/22。顶部工作区名称16/24px，低于内容页主标题。HTML heading层级不直接决定视觉字号，按所属内容角色映射。

导航13/20px；正文、表单及主要按钮14px；客户卡片摘要、次要描述、筛选标签／值／下拉选项12/18px；时间与来源12/18px；状态、分类、计数短标签11/16px。11px不用于段落、表单或操作名称。缩小字号不缩小40px桌面／44px移动点击区域，长篇会议与Agent阅读内容维持15px，富文本用户格式不覆盖。

客户列表姓名14/22px、摘要12/18px、标签11/16px；联系人详情标题22/30px、分区16/24px、分组14/22px。国内／海外、个人／团队共享以上尺度，仅主题色与字体不同。验收同时检查短标签对比度与长名称换行。

### UI-NAV-02 · 团队一级入口

展开侧栏必须显示团队成员、设备查看（管理员）、空间设置、开放API调用；禁止在展开状态用font-size:0隐藏名称。手动收起或761–1100px自动收起只隐藏文字span，保留图标、aria-label、title与当前项状态；移动导航沿用原有功能权限。修改后验证展开→收起→展开以及窗口缩放，不能只断言DOM中存在文案。

本轮范围与验收记录见 [UI调整交付](../docs/ui-typography-20261013.md)。
