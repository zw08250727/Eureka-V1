# SPC · 产品与前端协作规范

版本：1.0 / 2026-10-12。SPC 是本仓库的规范入口，适用于国内和海外、个人和团队。以下规范与当前有效业务基线共同作为 PM 交接及变更评审依据。

- [有效业务基线](business-baseline.md)：共享规则、账号隔离、冲突处理。
- [UI 规范](ui.md)：视觉变量、页面结构、交互状态、无障碍与响应式。
- [前端组件规范](components.md)：组件边界、数据访问、表单与弹窗、市场配置。
- [PM 协作与验收](workflow.md)：模块职责、跨模块依赖、提交及发布流程。
- [模块清单](modules.json)：评审总览的结构化来源；负责人姓名待填写。

交互演示：根路径为分流页，`/cn/` 与 `/global/` 为固定登录入口；`/review/` 为统一评审总览。PRD 继续集中维护在 `src/prototype/prd/content.json`，保留现有编辑、导入导出及发布方式。

规范冲突时必须记录待决策项，不以修改日期或测试是否通过自动推定业务结论。业务总则已明确替代的旧文案和旧测试需同步修正；历史原型保留用于回溯。
