# SPC · 产品与前端协作规范

版本：1.1 / 2026-10-13。SPC 是本仓库的规范入口，适用于国内和海外、个人和团队。以下规范与当前有效业务基线共同作为 PM 交接及变更评审依据。前端研发与两地 UI 规范已确认；本次落地文档和架构检查，视觉与组件目标随模块迭代实施。

- [有效业务基线](business-baseline.md)：共享规则、账号隔离、冲突处理。
- [前端研发规范](frontend.md)：FE 规则、组件工程、历史兼容边界、自动门槛及实施阶段。
- [公共 UI 规范](ui.md)：共用字号、间距、尺寸、状态、无障碍与响应式。
- [国内 UI 规范](ui-cn.md)：百智色值、字体、组件映射与场景边界。
- [海外 UI 规范](ui-global.md)：EurekaMind 色值、字体、组件映射与国际化要求。
- [前端组件规范](components.md)：组件边界、数据访问、表单与弹窗、市场配置。
- [PM 协作与验收](workflow.md)：模块职责、跨模块依赖、提交及发布流程。
- [PM 迭代模板](pm-change-template.md)：复用清单、状态矩阵、验证证据与 AI 实施约束。
- [架构例外登记](architecture-policy.json)：精确历史文件、受控富文本、遗留依赖及冻结基线指纹；不可自动更新绕过检查。
- [模块清单](modules.json)：评审总览的结构化来源；负责人姓名待填写。

交互演示：根路径为分流页，`/cn/` 与 `/global/` 为固定市场游客首页，私有操作唤起登录覆盖层；`/review/` 为统一评审总览。

规范冲突时必须记录待决策项，不以修改日期或测试是否通过自动推定业务结论。业务总则已明确替代的旧文案和旧测试需同步修正；历史原型保留用于回溯。
