## 字体、密度与布局

目标字体栈：`system-ui, -apple-system, "Segoe UI", "PingFang SC", "Microsoft YaHei", sans-serif`。支持中文回退，不要求新增远程字体。

| 用途 | 字号／行高 | 字重 |
| --- | --- | --- |
| 常规页面标题 | 24／32px | 600 |
| 首页主要标题 | 28／36px | 600 |
| 模块标题 | 18／26px | 600 |
| 卡片／弹窗分组标题 | 16／24px | 600 |
| 正文、表单、表格 | 14／22px | 400 |
| 按钮、导航、字段标签 | 14／20px | 500 |
| 辅助说明、时间、状态 | 12／18px | 400 |
| 会议／Agent 长正文 | 15／24px | 400 |
| 代码、技术标识 | 13／20px，等宽字体 | 400 |

间距使用 4／8／12／16／20／24／32／40／48px。图文 8px，表单项 20px，标准卡片内边距 24px，紧凑卡片 16px，模块间 24px。桌面内容边距 24px，窄屏 16px。侧栏沿用展开 272px／收起 76px；默认导航行 40px、触控 44px。更多尺寸以公共规范为唯一共用来源。

## 国际化与业务边界

- 保留白底居中登录覆盖层和现有 Google／Apple、邮箱渠道，不按主题变更登录流程。
- 金额从订单或市场配置读取币种，不以换汇生成另一市场价格。
- 语言、日期格式和时区分别配置；正式多语言化时同步 document lang 与相关可访问名称。现有 zh-CN 根语言不代表已经完成国际化。
- 使用 Intl 等格式化能力，禁止在 CSS 伪元素中拼接翻译文案；完整翻译不能依赖字符串替换。
- 以文案扩展约 30% 验证按钮、菜单和表格；避免依赖固定文字宽度。
- 长邮箱、名称、连接器 URL 有明确换行或截断策略；必要完整内容可通过可访问方式查看。
- 市场切换保持账号域独立，不能因共用组件读取国内会话或复制数据。

## 验收和来源

覆盖 390／768／1080／1440px，游客及登录后、相关个人／团队角色、渠道登录、弹窗和菜单、错误与只读状态。检查长文本、金额、时区和 body 浮层主题；主题变化同时验证国内不受影响。

现有颜色依据仓库 market token，其余为本次确认的 UI 目标值。海外 UI 规范不暗示当前已完成英文翻译或接入真实国际服务。
